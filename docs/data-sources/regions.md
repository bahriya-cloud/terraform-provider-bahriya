# bahriya_regions (Data Source)

Lists the Bahriya regions. Set `status_filter` to list only the regions with that status.

## Example Usage

### Every active region

```terraform
data "bahriya_regions" "active" {
  status_filter = "active"
}

output "region_ids" {
  value = [for r in data.bahriya_regions.active.regions : r.id]
}
```

### A project in every active region

```terraform
data "bahriya_regions" "active" {
  status_filter = "active"
}

resource "bahriya_project" "web" {
  handle  = "web-prod"
  name    = "Web Production"
  regions = [data.bahriya_regions.active.regions[0].id]
}
```

### Every region, whatever its status

```terraform
data "bahriya_regions" "all" {}
```
