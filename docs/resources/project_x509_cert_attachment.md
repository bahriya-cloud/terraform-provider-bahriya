# bahriya_project_x509_cert_attachment (Resource)

Attaches an x509 certificate to a project, so the project's containers can use it. The certificate itself belongs to the organisation and is managed with `bahriya_x509_cert`; one certificate can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the certificate from the project and never deletes the certificate.

## Example Usage

```terraform
variable "client_cert" {
  type = string
}

resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_x509_cert" "client_cert" {
  handle = "client-cert"
  name   = "Client certificate"
  cert   = var.client_cert
}

resource "bahriya_project_x509_cert_attachment" "web_x509_cert" {
  project_id = bahriya_project.web.id
  handle     = bahriya_x509_cert.client_cert.handle
}
```
