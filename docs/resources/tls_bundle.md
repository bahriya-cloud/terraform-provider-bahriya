# bahriya_tls_bundle (Resource)

A vault TLS bundle: a CA certificate, a server certificate and the matching private key, stored together, encrypted at rest and versioned. Changing `ca`, `cert` or `key` creates a new version and makes it current. The certificate details (`subject`, `issuer`, `expires` and the rest) are read from the certificate and returned on every read.

A container mounts its TLS bundles in `vault.tls_bundles`. A MySQL or Valkey instance can serve one with `security.tls_bundle`.

## Example Usage

```terraform
variable "ca_path" {
  type        = string
  description = "Path to the PEM-encoded CA certificate."
}

variable "cert_path" {
  type        = string
  description = "Path to the PEM-encoded server certificate."
}

variable "tls_private_key" {
  type        = string
  sensitive   = true
  description = "The PEM-encoded private key."
}

resource "bahriya_tls_bundle" "edge" {
  handle = "edge-tls"
  name   = "Edge TLS"
  ca     = file(var.ca_path)
  cert   = file(var.cert_path)
  key    = var.tls_private_key
}
```

## Schema

### Required

- `ca` (String) PEM-encoded CA certificate.
- `cert` (String) PEM-encoded server certificate.

- `managed_by` (String) Identifier (UUID) of the platform resource that manages this TLS bundle, such as a MySQL instance. Null when the organisation manages it.

- `organisation` (String) Identifier (UUID) of the organisation that owns the TLS bundle.

- `subject` (String) Distinguished name of the server certificate subject.
- `updated` (Attributes) When the TLS bundle was last changed (UTC). (see [below for nested schema](#nestedatt--updated))
- `version_count` (Number) Number of stored versions, including the version in use.

## Import

Import a TLS bundle by its UUID:

```shell
terraform import bahriya_tls_bundle.edge 065df92e-4e46-436a-a0a0-aaaaaaaaaaaa
```

~> **Note:** The API never returns `ca`, `cert` or `key`. After importing, set all three in your configuration; the next apply writes them as a new version. To read a bundle's CA certificate without managing the bundle, use the `bahriya_tls_bundle` data source.
