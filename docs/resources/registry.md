# bahriya_registry (Resource)

A registry credential: the server, username and password used to pull private container images. The password is encrypted at rest and versioned, and the API never returns it. Changing `password` creates a new version and makes it current.

A container names its registry in `workload.registry`, by the registry's ID.

Registry handles are released when the registry is deleted, so a handle can be reused. Project and container handles are not.

## Example Usage

### GitHub Container Registry

```terraform
variable "ghcr_username" {
  type = string
}

variable "ghcr_token" {
  type      = string
  sensitive = true
}

resource "bahriya_registry" "ghcr" {
  handle   = "ghcr"
  name     = "GitHub Container Registry"
  server   = "ghcr.io"
  username = var.ghcr_username
  password = var.ghcr_token
}
```

### Docker Hub

variable "docker_username" {

  type      = string

### Pulling an image through the registry

```terraform
# A container pulls its image from a registry, referenced by the registry's ID.

variable "ghcr_username" {
  type = string
}

variable "ghcr_token" {
  type      = string
  sensitive = true
}

resource "bahriya_registry" "ghcr" {
  handle   = "ghcr"
  name     = "GitHub Container Registry"
  server   = "ghcr.io"
  username = var.ghcr_username
  password = var.ghcr_token
}

resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_container" "api" {
  project = bahriya_project.web.id
  handle  = "api"
  name    = "API Server"
  regions = ["falkenstein-1"]

  workload = {
    image    = "ghcr.io/myorg/api:1.0.0"
    registry = bahriya_registry.ghcr.id
    cpu      = 250
    memory   = 256
  }
}
```

## Schema

### Required

- `handle` (String) Short identifier of the registry, unique within the organisation. Lowercase letters, digits and hyphens only.
- `name` (String) Display name of the registry, at most 100 characters.
- `password` (String, Sensitive) Password or access token for signing in to the registry. It is never returned in plaintext: reads return a placeholder in its place, and sending that placeholder back leaves the stored password unchanged. A change to the server, user name or password is kept as a new version.
- `server` (String) Host name of the container registry that images are pulled from, such as ghcr.io.
- `username` (String) User name for signing in to the registry.

### Read-Only

- `billable` (Boolean) Whether the registry is billed to the organisation.
- `created` (Attributes) When the registry was created (UTC). (see [below for nested schema](#nestedatt--created))
- `currentversion` (Number) Number of the version in use.
- `currentversionid` (String) Identifier (UUID) of the version in use.
- `id` (String) Unique identifier (UUID) of the registry, assigned by the platform.
- `managed_by` (String) Identifier (UUID) of the platform resource that manages this registry. Null when the organisation manages it.
- `managedbyresourcetype` (String) Type of the platform resource that manages this registry. Null when the organisation manages it. A managed registry can be changed only by that resource.
- `max_versions` (Number) Number of versions kept. When there are more, the oldest are deleted; the version in use is never deleted. It is 5 by default and cannot be set through this API.
- `rotated_at` (Attributes) When the version in use was written (UTC). Null until the registry has been rotated at least once. After a rollback, the date of the version rolled back to. (see [below for nested schema](#nestedatt--rotated_at))
- `updated` (Attributes) When the registry was last changed (UTC). (see [below for nested schema](#nestedatt--updated))
- `version_count` (Number) Number of stored versions, including the version in use.

## Import

Import a registry by its UUID:

```shell
terraform import bahriya_registry.ghcr 065df92e-4e46-436a-a0a0-aaaaaaaaaaaa
```

~> **Note:** The API never returns the password. After importing, set `password` in your configuration; the next apply writes it as a new version.
