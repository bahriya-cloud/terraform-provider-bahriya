# bahriya_project_env_file_attachment (Resource)

Attaches an env file to a project, so the project's containers can use it. The env file itself belongs to the organisation and is managed with `bahriya_env_file`; one env file can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the env file from the project and never deletes the env file.

## Example Usage

```terraform
resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_env_file" "app_env" {
  handle  = "app-env"
  name    = "Application environment"
  content = "LOG_LEVEL=info\nCACHE_TTL=300\n"
}

resource "bahriya_project_env_file_attachment" "web_env_file" {
  project_id = bahriya_project.web.id
  handle     = bahriya_env_file.app_env.handle
}
```

## Import

Import an attachment by the project's UUID and the env file's handle, separated by a colon:

```shell
terraform import bahriya_project_env_file_attachment.web_env_file \
  8a3d0000-1111-2222-3333-444444444444:app-env
```
