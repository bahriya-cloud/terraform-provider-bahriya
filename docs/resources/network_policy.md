# bahriya_network_policy (Resource)

A network policy is a reusable set of rules, owned by the organisation, for the traffic allowed to and from the workloads it applies to. Apply it to a whole project with `bahriya_project_network_policy_attachment`, or to one workload with that workload's network policy list: `networking.network_policies` on a container, MySQL or Valkey instance, and `network_policies` on a Memcached instance.

Without a policy, a project's workloads can reach each other and the internet. A policy narrows that:

- Incoming traffic is limited to the projects named in `ingress_peers`.
- Once `egress_cidrs` or `egress_fqdns` is set, outgoing traffic is refused unless it goes to an address or domain on the list. DNS lookups are always allowed.
- `egress_fqdns` filters by domain name, which turns on `enable_l7`. Filtering by domain adds a charge per replica for every container the policy applies to.

## Example Usage

```terraform
resource "bahriya_network_policy" "web_tier" {
  name   = "Web tier"
  handle = "web-tier"

  # Ingress: only these projects of the same organisation may reach the targets.
  ingress_peers = ["frontend", "gateway"]

  # Egress (L3/L4): outbound traffic is restricted to these CIDRs on the listed ports.
  egress_cidrs = ["10.0.0.0/8", "203.0.113.0/24"]

  ports = [
    { port = 443, protocol = "TCP" },
    { port = 53, protocol = "UDP" },
  ]
}

# L7 egress: allow specific domains. Setting egress_fqdns enables enable_l7,
# which adds a per-replica charge for every container the policy is applied to.
resource "bahriya_network_policy" "notifications" {
  name         = "Notifications to partner"
  handle       = "notifications-to-partner"
  egress_fqdns = ["api.partner.example.com"]
}
```

## Schema

### Required

- `handle` (String) DNS-1123 compliant: lowercase alphanumeric and hyphens only.
- `name` (String) Display name of the network policy.

### Optional

- `egress_cidrs` (List of String) CIDR ranges this policy's targets are allowed to send outbound traffic to.
- `egress_fqdns` (List of String) Domain names allowed for outbound traffic. Coming soon — stored and validated now, enforced in a future release.
- `enable_l7` (Boolean) Enable L7 controls for this policy. Opts the policy into the application-layer engine and its per-replica charge for every container it is applied to. Automatically enabled when egress domains are set.
- `ingress_peers` (List of String) Same-organisation project handles allowed to reach this policy's targets.
- `ports` (Attributes List) Optional port/protocol scoping applied to the rules above. Omit to allow all ports. (see [below for nested schema](#nestedatt--ports))

- `id` (String) Unique identifier (UUID) of the network policy, assigned by the platform.
