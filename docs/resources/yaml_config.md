# bahriya_yaml_config (Resource)

A YAML config: a versioned YAML document that any container in a project it is attached to can mount as a file. The content is checked as YAML on every create and update. Changing `content` creates a new version and makes it current.

A container mounts its YAML configs in `configs.yaml_configs`.

## Example Usage

```terraform
resource "bahriya_yaml_config" "app" {
  handle  = "app-yaml"
  name    = "App YAML"
  content = <<-EOT
    server:
      port: 8080
      timeout: 30s
    features:
      beta: false
  EOT
}
```

## Schema

### Required

- `content` (String) Valid YAML content.
- `handle` (String) DNS-1123 compliant: lowercase alphanumeric and hyphens only.
- `name` (String) Display name of the YAML config, at most 100 characters.

### Read-Only

- `billable` (Boolean) Whether the YAML config is billed to the organisation.
- `created` (String) When the YAML config was created (UTC).
- `current_version` (Number) Number of the version in use.
- `id` (String) Unique identifier (UUID) of the YAML config, assigned by the platform.
- `managed_by` (String) Identifier (UUID) of the platform resource that manages this YAML config, such as a MySQL instance. Null when the organisation manages it.
- `managed_by_type` (String) Type of the platform resource that manages this YAML config, such as mysql. Null when the organisation manages it. A managed YAML config can be changed only by that resource.
- `max_versions` (Number) Number of versions kept. When there are more, the oldest are deleted; the version in use is never deleted. It is 5 by default and cannot be set through this API.
- `organisation` (String) Identifier (UUID) of the organisation that owns the YAML config.
- `rotated_at` (String) When the version in use was written (UTC). Null until the YAML config has been rotated at least once. After a rollback, the date of the version rolled back to.
- `updated` (String) When the YAML config was last changed (UTC).
- `version_count` (Number) Number of stored versions, including the version in use.

## Import

Import a YAML config by its UUID:

```shell
terraform import bahriya_yaml_config.app 065df92e-4e46-436a-a0a0-aaaaaaaaaaaa
```

~> **Note:** The API never returns a config's content. After importing, set `content` in your configuration; the next apply writes it as a new version.
