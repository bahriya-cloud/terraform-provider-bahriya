# bahriya_project_secret_attachment (Resource)

Attaches a secret to a project, so the project's containers can use it. The secret itself belongs to the organisation and is managed with `bahriya_secret`; one secret can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the secret from the project and never deletes the secret.

## Example Usage

```terraform
variable "db_password" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_secret" "db_password" {
  handle = "db-password"
  name   = "Database password"
  value  = var.db_password
}

resource "bahriya_project_secret_attachment" "web_secret" {
  project_id = bahriya_project.web.id
  handle     = bahriya_secret.db_password.handle
}
```
