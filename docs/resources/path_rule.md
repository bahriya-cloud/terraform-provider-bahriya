# bahriya_path_rule (Resource)

A path rule applies basic authentication, rate limiting, or IP allow and deny lists to one URL prefix of an HTTP container. For each request the rule with the longest matching `path` applies, and each control it sets replaces the container's own setting for that control on that path.

A path rule belongs to the container named in `container`. Its handle only has to be unique among the container's current rules, so a replacement rule can reuse it.

## Example Usage

### Basic authentication on an admin area

```terraform
variable "admin_password" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "web" {
  name    = "Web"
  handle  = "web"
  regions = ["falkenstein-1"]
}

resource "bahriya_container" "api" {
  name    = "API"
  handle  = "api"
  project = bahriya_project.web.id
  regions = ["falkenstein-1"]

  workload = {
    image  = "ghcr.io/myorg/api:1.2.3"
    port   = "3000"
    cpu    = "250"
    memory = "256"
  }

  scaling = {
    replicas = "1"
  }
}

resource "bahriya_path_rule" "admin" {
  container = bahriya_container.api.id
  handle    = "admin"
  path      = "/api/admin"

  security = {
    basic_auth_enabled = true
    basic_auth = [
      {
        username = "alice"
        password = var.admin_password
      },
    ]
  }
}
```

### Rate limiting on a webhook endpoint

```terraform
resource "bahriya_project" "web" {
  name    = "Web"
  handle  = "web"
  regions = ["falkenstein-1"]
}

resource "bahriya_container" "api" {
  name    = "API"
  handle  = "api"
  project = bahriya_project.web.id
  regions = ["falkenstein-1"]

  workload = {
    image  = "ghcr.io/myorg/api:1.2.3"
    port   = "3000"
    cpu    = "250"
    memory = "256"
  }

  scaling = {
    replicas = "1"
  }
}

resource "bahriya_path_rule" "webhook" {
  container = bahriya_container.api.id
  handle    = "webhook"
  path      = "/webhook"

  security = {
    rate_limiting = {
      enabled    = true
      per_minute = 60
      per_hour   = 1000
    }
  }
}
```

### Several controls on an internal endpoint

```terraform
variable "ops_password" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "web" {
  name    = "Web"
  handle  = "web"
  regions = ["falkenstein-1"]
}

resource "bahriya_container" "api" {
  name    = "API"
  handle  = "api"
  project = bahriya_project.web.id
  regions = ["falkenstein-1"]

  workload = {
    image  = "ghcr.io/myorg/api:1.2.3"
    port   = "3000"
    cpu    = "250"
    memory = "256"
  }

  scaling = {
    replicas = "1"
  }
}

resource "bahriya_path_rule" "internal" {
  container = bahriya_container.api.id
  handle    = "internal-tools"
  path      = "/internal"
  priority  = 100

  security = {
    ip_allowlist = {
      enabled = true
      ips     = ["10.0.0.0/8", "192.168.0.0/16"]
    }

    basic_auth_enabled = true
    basic_auth = [
      {
        username = "ops"
        password = var.ops_password
      },
    ]
  }
}
```

## Import

Import a path rule by its container's UUID and its own UUID, separated by a colon:

```shell
terraform import bahriya_path_rule.admin \
  c0ffee00-aaaa-bbbb-cccc-000000000001:dd0ffee0-1111-2222-3333-444444444444
```

~> **Note:** The API never returns basic authentication passwords. After importing, set each `security.basic_auth` password in your configuration; the next apply writes them.
