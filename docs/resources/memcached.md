# bahriya_memcached (Resource)

A managed Memcached instance: an in-memory cache, run in every region of `regions`, that the containers of its project connect to. `topology` sets the number of nodes and `tuning` sets the memory, connection and thread limits of each node.

Creating, changing and deleting an instance is asynchronous. The provider waits up to 20 minutes for the instance to reach `running`, or `terminated` on delete. If a create does not settle in time, the instance is saved to state with its current status and a warning; run `terraform apply` again to check it.

## Example Usage

### A basic instance

```terraform
resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_memcached" "session" {
  handle  = "session-cache"
  name    = "Session Cache"
  regions = ["falkenstein-1"]
  project = bahriya_project.web.id

  tuning = {
    memory = 512
  }
}
```

### A tuned instance

```terraform
resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_memcached" "api_cache" {
  handle  = "api-cache"
  name    = "API Response Cache"
  regions = ["falkenstein-1"]
  project = bahriya_project.web.id

  topology = {
    nodes = 3
  }

  tuning = {
    memory           = 1024
    max_connections  = 2048
    threads          = 8
    max_item_size_mb = 5
  }
}
```
