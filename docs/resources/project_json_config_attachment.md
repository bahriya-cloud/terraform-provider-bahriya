# bahriya_project_json_config_attachment (Resource)

Attaches a JSON config to a project, so the project's containers can use it. The config itself belongs to the organisation and is managed with `bahriya_json_config`; one config can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the config from the project and never deletes the config.

## Example Usage

```terraform
resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_json_config" "feature_flags" {
  handle  = "feature-flags"
  name    = "Feature flags"
  content = jsonencode({ new_checkout = true })
}

resource "bahriya_project_json_config_attachment" "web_json_config" {
  project_id = bahriya_project.web.id
  handle     = bahriya_json_config.feature_flags.handle
}
```
