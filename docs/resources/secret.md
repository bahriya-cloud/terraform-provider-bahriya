# bahriya_secret (Resource)

A vault secret: an encrypted, versioned value that containers read as an environment variable. Changing `value` creates a new version and makes it current.

Secret handles are released when the secret is deleted, so a handle can be reused.

## Example Usage

### Create a secret

```terraform
variable "db_password" {
  type      = string
  sensitive = true
}

resource "bahriya_secret" "db_password" {
  name   = "Database password"
  handle = "db-password"
  value  = var.db_password
}
```

### Read it in a container

A container names its secrets in `workload.secrets`: the environment variable on the left, the secret's handle on the right.

```terraform
variable "db_password" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "shop" {
  name    = "Shop"
  handle  = "shop"
  regions = ["helsinki-1"]
}

resource "bahriya_secret" "db_password" {
  name   = "Database password"
  handle = "db-password"
  value  = var.db_password
}

resource "bahriya_container" "api" {
  name    = "API"
  handle  = "api"
  project = bahriya_project.shop.id
  regions = ["helsinki-1"]

  workload = {
    image  = "registry.example.com/shop/api:1.0.0"
    cpu    = 250
    memory = 256
    secrets = {
      DATABASE_PASSWORD = bahriya_secret.db_password.handle
    }
  }
}
```

## Import

Import a secret by its UUID:

```shell
terraform import bahriya_secret.db_password 065df92e-4e46-436a-a0a0-aaaaaaaaaaaa
```

~> **Note:** The API never returns a secret's value. After importing, set `value` in your configuration; the next apply writes it as a new version.
