# bahriya_resource_grant (Resource)

Grants one organisation member a set of permissions on **one resource**: a container, a Memcached instance, or a vault item, config, registry or network policy.

A grant only ever adds access. It never removes access the member already has through their role, and it affects nothing but that one resource. The member must already belong to the organisation.

A grant cannot be changed in place, so changing any attribute, the permissions included, replaces it: the old grant is revoked and a new one is created.

## Example Usage

### Share a container, with read and update

```terraform
resource "bahriya_project" "web" {
  name    = "Web"
  handle  = "web"
  regions = ["falkenstein-1"]
}

resource "bahriya_container" "api" {
  name    = "API"
  handle  = "api"
  project = bahriya_project.web.id
  regions = ["falkenstein-1"]

  workload = {
    image  = "ghcr.io/myorg/api:1.2.3"
    port   = "3000"
    cpu    = "250"
    memory = "256"
  }

  scaling = {
    replicas = "1"
  }
}

resource "bahriya_resource_grant" "share_api_container" {
  to_user       = "5f9c1a2b-3d4e-4f60-8a1b-2c3d4e5f6071"
  resource_type = "deployables_container_http"
  resource_id   = bahriya_container.api.id
  permissions   = ["read", "update"]
}
```

### Share a registry, read only

```terraform
variable "contractor_user_id" {
  type = string
}

variable "ghcr_username" {
  type = string
}

variable "ghcr_token" {
  type      = string
  sensitive = true
}

resource "bahriya_registry" "ghcr" {
  name     = "GitHub Container Registry"
  handle   = "ghcr"
  server   = "ghcr.io"
  username = var.ghcr_username
  password = var.ghcr_token
}

resource "bahriya_resource_grant" "share_registry" {
  to_user       = var.contractor_user_id
  resource_type = "attachables_registries"
  resource_id   = bahriya_registry.ghcr.id
  permissions   = ["read"]
}
```

## Schema

### Required

- `permissions` (Set of String) Permissions to grant on the instance: any of create, read, update, delete.
- `resource_id` (String) ID (UUID) of the specific instance to share.
- `resource_type` (String) Resource kind, such as deployables_container_http or attachables_registries.
- `to_user` (String) ID (UUID) of the member to share with. Must already be a member of the organisation.

### Read-Only

- `grant_ids` (List of String) The individual grant row IDs backing this share (one per permission).
- `id` (String) Synthetic identifier: '<resource_type>|<resource_id>|<to_user>'.
