# bahriya_project_yaml_config_attachment (Resource)

Attaches a YAML config to a project, so the project's containers can use it. The config itself belongs to the organisation and is managed with `bahriya_yaml_config`; one config can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the config from the project and never deletes the config.

## Example Usage

```terraform
resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_yaml_config" "app_config" {
  handle  = "app-config"
  name    = "Application configuration"
  content = yamlencode({ log_level = "info" })
}

resource "bahriya_project_yaml_config_attachment" "web_yaml_config" {
  project_id = bahriya_project.web.id
  handle     = bahriya_yaml_config.app_config.handle
}
```

### Required

- `handle` (String) Handle of the YAML config to attach.
- `project_id` (String) ID (UUID) of the project the YAML config is attached to.

### Read-Only

- `id` (String) Identifier of the attachment, in the form {project_id}:{handle}.
- `join_id` (String) Identifier the API gives this attachment. Empty after an import: the API does not return it for an existing attachment.

## Import

Import an attachment by the project's UUID and the config's handle, separated by a colon:

```shell
terraform import bahriya_project_yaml_config_attachment.web_yaml_config \
  8a3d0000-1111-2222-3333-444444444444:app-config
```
