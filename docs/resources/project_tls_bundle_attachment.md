# bahriya_project_tls_bundle_attachment (Resource)

Attaches a TLS bundle to a project, so the project's containers can use it. The TLS bundle itself belongs to the organisation and is managed with `bahriya_tls_bundle`; one TLS bundle can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the TLS bundle from the project and never deletes the TLS bundle.

## Example Usage

```terraform
variable "api_ca" {
  type = string
}

variable "api_cert" {
  type = string
}

variable "api_key" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_tls_bundle" "api_tls" {
  handle = "api-tls"
  name   = "API TLS"
  ca     = var.api_ca
  cert   = var.api_cert
  key    = var.api_key
}

resource "bahriya_project_tls_bundle_attachment" "web_tls_bundle" {
  project_id = bahriya_project.web.id
  handle     = bahriya_tls_bundle.api_tls.handle
}
```

  8a3d0000-1111-2222-3333-444444444444:api-tls
