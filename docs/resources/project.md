# bahriya_project (Resource)

A project groups containers and managed datastores (MySQL, Valkey and Memcached) inside an organisation. It runs in the regions listed in `regions`, and the organisation's vault items, configs, registries and network policies become available to it once attached with the `bahriya_project_*_attachment` resources.

Project handles are not released when a project is deleted, so a handle cannot be reused.

## Example Usage

### A project in one region

```terraform
resource "bahriya_project" "web" {
  handle  = "web-prod"
  name    = "Web Production"
  regions = ["falkenstein-1"]
}
```

### A project in several regions

```terraform
data "bahriya_regions" "active" {
  status_filter = "active"
}

resource "bahriya_project" "global" {
  handle  = "global-app"
  name    = "Global Application"
  regions = [for r in data.bahriya_regions.active.regions : r.id]
}
```

### Reading the project's allowance

Each project has a resource allowance in every region it runs in. The `effectivequota*` attributes report it; the `bahriya_project_quota` data source reports how much of it is in use.

```terraform
resource "bahriya_project" "web" {
  name    = "Web"
  handle  = "web"
  regions = ["falkenstein-1"]
}

output "cpu_headroom" {
  value = bahriya_project.web.effectivequotarequestcpu
}
```
