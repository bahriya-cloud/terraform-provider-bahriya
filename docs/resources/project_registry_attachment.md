# bahriya_project_registry_attachment (Resource)

Attaches a registry to a project, so the project's containers can use it. The registry itself belongs to the organisation and is managed with `bahriya_registry`; one registry can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the registry from the project and never deletes the registry.

## Example Usage

```terraform
variable "ghcr_username" {
  type = string
}

variable "ghcr_token" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_registry" "ghcr" {
  handle   = "ghcr"
  name     = "GitHub Container Registry"
  server   = "ghcr.io"
  username = var.ghcr_username
  password = var.ghcr_token
}

resource "bahriya_project_registry_attachment" "web_registry" {
  project_id = bahriya_project.web.id
  handle     = bahriya_registry.ghcr.handle
}
```

## Import

Import an attachment by the project's UUID and the registry's handle, separated by a colon:

```shell
terraform import bahriya_project_registry_attachment.web_registry \
  8a3d0000-1111-2222-3333-444444444444:ghcr
```
