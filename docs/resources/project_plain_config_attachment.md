# bahriya_project_plain_config_attachment (Resource)

Attaches a plain-text config to a project, so the project's containers can use it. The config itself belongs to the organisation and is managed with `bahriya_plain_config`; one config can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the config from the project and never deletes the config.

## Example Usage

```terraform
resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_plain_config" "nginx_conf" {
  handle  = "nginx-conf"
  name    = "Nginx configuration"
  content = "worker_processes auto;\n"
}

resource "bahriya_project_plain_config_attachment" "web_plain_config" {
  project_id = bahriya_project.web.id
  handle     = bahriya_plain_config.nginx_conf.handle
}
```
