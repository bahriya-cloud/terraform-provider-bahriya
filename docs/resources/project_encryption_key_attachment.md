# bahriya_project_encryption_key_attachment (Resource)

Attaches an encryption key to a project, so the project's containers can use it. The key itself belongs to the organisation and is managed with `bahriya_encryption_key`; one key can be attached to many projects.

Changing `project_id` or `handle` replaces the attachment. Removing the attachment detaches the key from the project and never deletes the key.

## Example Usage

```terraform
variable "data_key" {
  type      = string
  sensitive = true
}

resource "bahriya_project" "web" {
  handle  = "web"
  name    = "Web"
  regions = ["falkenstein-1"]
}

resource "bahriya_encryption_key" "data_key" {
  handle = "data-key"
  name   = "Data encryption key"
  format = "base64"
  key    = var.data_key
}

resource "bahriya_project_encryption_key_attachment" "web_encryption_key" {
  project_id = bahriya_project.web.id
  handle     = bahriya_encryption_key.data_key.handle
}
```
