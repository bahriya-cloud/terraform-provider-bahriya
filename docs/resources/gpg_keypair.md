# bahriya_gpg_keypair (Resource)

A vault GPG (OpenPGP) keypair: an ASCII-armoured public key and its private key, stored together, encrypted at rest and versioned. The API never returns either key. Changing `public_key` or `private_key` creates a new version and makes it current.

A container mounts its GPG keypairs in `vault.gpg_keypairs`.

## Example Usage

```terraform
variable "signing_public_key_path" {
  type        = string
  description = "Path to the ASCII-armoured public key, such as signing.pub.asc."
}

variable "signing_private_key" {
  type        = string
  sensitive   = true
  description = "The ASCII-armoured private key."
}

resource "bahriya_gpg_keypair" "signing" {
  handle      = "release-signing"
  name        = "Release Signing Key"
  public_key  = file(var.signing_public_key_path)
  private_key = var.signing_private_key
}
```

## Import

Import a GPG keypair by its UUID:

```shell
terraform import bahriya_gpg_keypair.signing 065df92e-4e46-436a-a0a0-aaaaaaaaaaaa
```

~> **Note:** The API never returns the keys. After importing, set `public_key` and `private_key` in your configuration; the next apply writes them as a new version.
