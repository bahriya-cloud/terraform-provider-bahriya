# bahriya_role (Resource)

A **custom** organisation role: a named set of permissions that you assign to members. Each entry in `permissions` grants one permission on one kind of resource, at the organisation or project level.

The system roles (`owner`, `admin`, `member` and `viewer`) are managed by Bahriya and cannot be created, changed or deleted with this resource. This resource only defines a role; assign members to it in the console or with `reis role:assign`.

## Example Usage

### A deployer role

```terraform
resource "bahriya_role" "deployer" {
  name        = "Deployer"
  description = "Manage containers; read-only on credentials."

  permissions = [
    {
      level      = "project"
      resource   = "deployables_container_http"
      permission = "create"
    },
    {
      level      = "project"
      resource   = "deployables_container_http"
      permission = "update"
    },
    {
      level      = "project"
      resource   = "deployables_container_http"
      permission = "delete"
    },
    {
      level      = "organisation"
      resource   = "attachables_registries"
      permission = "read"
    },
  ]
}
```

## Import

Import a role by its UUID:

```shell
terraform import bahriya_role.deployer 7a1e2c3d-4b5f-4061-9a2b-3c4d5e6f7081
```

A system role can be imported, but any change to it fails, because system roles cannot be changed.
